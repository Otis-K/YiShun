# Tool Plus 第二批完整实现与验收方案

版本目标：0.4.0  
范围：完整文件分类、图片新格式与效果、音视频补充操作、PDF 压缩/提图/页码/元数据、Word/Excel/PPT 内嵌图片处理。

## 实现原则

- 不引入 Aspose、Spire、LibreOffice 或其他 Office/PDF 商业转换引擎。
- 继续使用 Electron 前端、Go 主后端，以及安装包已经携带的 FFmpeg、pdfcpu、ExifTool 和 Python PDF bridge。
- 所有操作输出新文件，不覆盖原文件；输出路径必须返回前端并允许直接打开。
- 每个后端工具必须存在对应前端卡片、中文说明和必要参数控件。
- 测试样本、压力输出和验收报告只放在 `G:\tool-user-file`，不进入安装包。

## 功能矩阵

### 完整文件分类

`classify-advanced` 提供九种分类规则：首字符、首字母或汉字、连续数字、开头字符、末尾字符、指定位置、正则表达式、文件大小、修改年月。正则规则优先使用第一个捕获组；无匹配文件进入“未匹配”。所有目录名经过 Windows 非法字符清理。

### 图片新格式与效果

- `image-modern-convert`：WebP、AVIF、TGA、PSD、SVG。
- PSD 使用 Go 原生写入未压缩 8-bit RGB PSD；SVG 使用 data URI 封装原图并保留像素尺寸；WebP/AVIF/TGA 使用安装包内 FFmpeg。
- `image-effects`：灰度、棕褐色、亮度、对比度、模糊、锐化、反相，保留透明通道并输出新文件。

### 视频与音频

- 视频直接转 AAC、OGG、OPUS。
- 视频时间段截取、合并、分辨率、帧率和码率调整。
- 音视频音量调整、音频合并、音频加纯色或自定义封面转 MP4。
- 所有数值参数设置上下限；不支持的输入扩展名立即失败，不进入长时间误解析。

### PDF

- `pdf-compress`：pdfcpu 无损结构优化，清理未使用或重复资源。
- `pdf-extract-images`：提取 PDF 内原始图片资源，不把整页截图伪装成提图。
- `pdf-page-numbers`：当前页、总页数、起始编号、字号和六种位置。
- `pdf-metadata`：设置或清除标题、作者、主题、关键词。

### Office 内嵌图片

- DOCX、XLSX、PPTX 分别提供导出、删除、替换三个入口。
- 导出直接读取 OOXML 包的 `word/media`、`xl/media`、`ppt/media`，不降质。
- 删除同时移除图片媒体、绘图节点和图片关系。
- 替换按原媒体扩展名转换替换图，保留原有关系、锚点、位置和尺寸。
- 仅支持现代 OOXML 文件，不把 `.doc/.xls/.ppt` 冒充为已支持。

## 验收门槛

1. 后端目录数量、前端元数据数量和工作区目录数量一致。
2. 每个新增入口至少执行一次成功路径；关键参数至少执行一个边界失败路径。
3. 图片输出必须能重新解码；PSD、SVG 还需检查格式签名和尺寸。
4. 音视频输出使用 ffprobe 检查流类型、时长、分辨率、帧率和编码。
5. PDF 使用 pdfinfo/pypdf 检查页数，使用 Poppler 渲染代表页进行视觉检查，元数据用 ExifTool 读取回验。
6. DOCX 使用 Word/LibreOffice 渲染为 PNG 检查；XLSX 检查工作表、数据和媒体包；PPTX 渲染所有幻灯片并检查溢出。
7. 删除图片后的 Office 文件必须仍可打开并保留正文/单元格/幻灯片；替换后的媒体哈希必须变化且媒体数量不变。
8. 使用大图片、多页 PDF、30 秒 1080p 视频、多图 Office 文件和至少 500 个分类文件执行压力测试。
9. 执行完整旧回归，确保已有 86 项功能没有被第二批改动破坏。
10. 构建安装包后解包扫描，确认不包含 `stress`、`work`、测试样本和 `G:\tool-user-file`；再从安装后资源调用后端复验新增入口。

只有以上门槛全部满足，才能在 `DELIVERY_STATUS.md` 标记交付完成。
