# Tool Plus 0.5.21 画布素材与视频连线验收

日期：2026-07-19（Asia/Shanghai）

## 问题原因与修复

1. 生成视频后不能拖动：视频元素错误使用 `nodrag`，导致 React Flow 禁止从视频画面发起拖动。现仅播放控件阻止拖动，视频画面恢复为节点拖拽区。
2. 已生成图片不出现在素材列表：素材索引只接受 `status=success` 且只读取 `preview`。现兼容 `success/succeeded/completed`、恢复结果字段、生成节点类型推断及本地/空白素材。
3. 素材弹层不消失：Portal 弹层缺少拥有者范围外的捕获阶段关闭监听。现点击节点及弹层外任意区域会关闭。
4. 图片/视频连线没有进入 Seedance 参数：视频输入只读取单值并强制把首个输入当图片。现输入端口支持多值，保留真实媒体类型，并按以下规则映射：
   - 两张图片：`firstFrame + lastFrame`；
   - 单张图片：`referenceImages`（符合 Pro(431) 真实上游限制）；
   - 视频：`referenceVideos`；
   - 音频：`referenceAudios`。
