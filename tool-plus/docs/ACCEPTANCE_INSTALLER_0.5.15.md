# 安装器交互升级修复验收（0.5.15）

## 根因

electron-builder 26 的默认 NSIS `CHECK_APP_RUNNING` 在 PowerShell 可用时，会把所有可执行路径位于 `$INSTDIR` 下的进程判定为应用仍在运行。交互升级期间，旧卸载器可能短暂从安装目录启动，因此检测会尝试关闭卸载器自身，并误报“文档批量处理工具无法关闭”。

## 修复

- 覆盖 `customCheckAppRunning`，只精确关闭 `文档批量处理工具.exe`。
- 保留安装器启动阶段对 Tool Plus 自有 Electron/Go 子进程的清理。
- 安装、卸载和应用数据分离；不会删除 `G:\tool-plus-data` 用户画布数据。
- 推荐启动脚本继续强制使用 G 盘临时目录，规避 C 盘临时 DLL/内存映射异常。
