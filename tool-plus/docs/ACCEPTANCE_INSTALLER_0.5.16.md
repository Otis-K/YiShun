# One-click 原地升级验收（0.5.16）

## 真实根因

多页 assisted NSIS 升级会启动旧版交互卸载器。electron-builder 的旧卸载阶段存在进程误判，应用已经关闭后仍可能弹出“无法关闭/重试”。0.5.15 的自动验收又会向默认按钮发送回车，可能误点“重试”，因此该次验收结论作废。

## 最终方案

- 安装模式改为 one-click 原地升级，不再进入有问题的旧版交互卸载页面。
- 双击安装包即可安装；保留可见安装进度，但不要求选择目录或反复点击下一步。
- 安装器启动时关闭 Tool Plus 自有 Electron/Go 进程。
- 已安装用户沿用原安装目录；画布和配置数据仍在独立的 `G:\tool-plus-data`，升级不会删除。
- 推荐脚本强制使用 G 盘临时目录，避免 C 盘临时 DLL 和 NSIS 内存映射问题。
