# 非商业组件功能补齐与验收方案

## 1. 目标与边界

本批次在不引入 Aspose、Spire、LibreOffice、OpenOffice 或同类 Office/PDF 商业与替代引擎的前提下，完成以下五个功能域的前端、后端、真实文件和安装包闭环：

1. 完整文件分类。
2. 图片新格式与图片效果。
3. 视频与音频补充操作。
4. PDF 压缩、提取图片、添加页码和元数据处理。
5. DOCX、XLSX、PPTX 内嵌图片处理。

所有操作默认写入工作区对应工具的 `output` 目录，不覆盖输入文件。成功状态必须显示完整输出路径，并提供“打开保存位置”。

## 2. 功能规格

### 2.1 完整文件分类

统一入口支持递归扫描和以下互斥分类规则：

- 按完整扩展名分类，无扩展名进入“无扩展名”。
- 按第一个字符分类。
- 按第一个英文字母分类，非英文字母进入“其他”。
- 按第一个数字分类，非数字进入“其他”。
- 按文件名开头 N 个 Unicode 字符分类。
- 按文件名末尾 N 个 Unicode 字符分类。
- 按指定 Unicode 字符位置范围分类。
- 按用户正则表达式的第一个捕获组分类；无捕获组时使用完整匹配；未匹配进入“未匹配”。

分类目录名必须过滤 Windows 非法字符和保留名称。重名输出采用确定性的数字后缀，禁止静默覆盖。

### 2.2 图片新格式与效果

格式转换目标：WEBP、AVIF、TGA、PSD、SVG。SVG 输出采用包含原始位图数据的标准 SVG 容器，不声称进行矢量化。

效果处理支持：亮度、对比度、饱和度、锐化、模糊、灰度、棕褐色、自动对比度。参数必须有明确范围并在后端二次校验。保留透明通道的格式不得被无提示地铺黑；转 JPEG/TGA 等不支持透明通道的目标使用用户可选背景色。

### 2.3 视频与音频补充操作

- 视频提取 AAC、OGG、OPUS。
- 删除视频画面并仅输出音频。
- 音频生成 MP4，可选择纯色背景或封面图片。
- 视频按开始时间和时长截取。
- 视频裁剪，支持 x/y/宽/高并校验偶数尺寸和边界。
- 视频合并，要求兼容输入时无损拼接，不兼容时统一转码。
- 音频合并并统一采样率和声道。
- 调整音量。
- 调整分辨率、视频码率和帧率。

所有 FFmpeg 任务必须限制输入扩展名、覆盖输出、捕获 stderr，并在失败时删除不完整输出。

### 2.4 PDF 补充处理

- 压缩：安全、均衡、强力三个预设；输出后必须可重新打开且页数不变。
- 提取图片：导出 PDF 中的原始内嵌图片；无图片时明确报错，不以整页截图冒充内嵌图片。
- 添加页码：支持页脚左/中/右、起始编号、字体大小、页边距和页码模板。
- 元数据：读取、设置和清除 Title、Author、Subject、Keywords、Creator、Producer；始终生成新 PDF。

### 2.5 OOXML 内嵌图片

仅处理现代 OOXML：DOCX、XLSX、PPTX。三类文件均支持：

- 导出全部内嵌图片，并输出包含部件路径、关系引用和导出文件路径的 JSON 清单。
- 删除全部内嵌图片，同时清理关系和内容类型引用，输出的新文件必须可重新打开。
- 替换指定图片或全部图片；保持关系 ID，必要时同步扩展名和内容类型。

## 3. 前后端契约

新增工具必须进入后端 catalog，并在前端具有中文标题、分类、说明、参数定义、输入类型限制和多文件规则。前端只负责交互校验；后端必须独立完成同样的安全与范围校验。

批量任务返回全部输出路径。零输出不得标记成功。多文件合并类任务必须保持用户选择顺序。

## 4. 真实验收矩阵

测试样本位于安装包外部的 `G:\tool-user-file\stress-<version>`；不得进入 `app.asar` 或安装资源。

- 文件分类：10,000 个文件、20 层目录、中文名称、同名输出和 9 种分类规则；每种规则核对恰好 10,000 个结果。
- 图片：3000×2000 高熵 PNG 和 2048×2048 透明/半透明 PNG；每种目标格式重新解码或核对文件签名与尺寸，效果输出核对像素变化和 alpha 范围。
- 视频：30 秒 1080p H.264/AAC；音频 5 分钟 PCM；使用 FFmpeg 独立解码并核对流、分辨率和帧率。该规模覆盖完整转码路径，同时控制重复回归时长。
- PDF：80 页图片型 PDF；核对压缩后可读性、页数不变、首末页页码文本、80 张图片提取和 Unicode 元数据。
- DOCX/XLSX/PPTX：真实 10 页 17 图 DOCX、4 工作表 20,004 行/20 图片锚点 XLSX、真实 87 页 27 图 PPTX（含 WMF/EMF）；处理后验证 ZIP、XML、全部关系目标、媒体 SHA-256，并用 Word/Excel/PowerPoint 原生打开和渲染抽检。

每项同时覆盖无效输入、空输入、参数越界、只读输出目录、Unicode 路径和中途失败残留文件。验收报告记录耗时、输入大小、输出大小、输出数量、结构检查结果和 SHA-256。

## 5. 完成定义

只有同时满足以下条件才可标记完成：

- 功能入口、参数、后端处理、结果路径和打开目录形成闭环。
- 单元/集成回归全部通过。
- 大文件真实压力测试全部通过；预期失败边界准确失败。
- DOCX/XLSX/PPTX/PDF 可重新打开并通过结构检查和视觉抽检。
- 其他现有工具回归无退化。
- 干净安装包不包含测试文件、构建缓存或工作目录；安装后离线运行通过。
