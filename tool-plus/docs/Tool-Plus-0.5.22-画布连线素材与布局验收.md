# Tool Plus 0.5.22 画布连线、素材与布局验收

验收日期：2026-07-19

## 本次修复

- 连线支持右键取消、选中后工具栏取消、双击取消；均不删除节点。
- 图片/视频生成结果在重启后仍可进入画布素材库；旧版保存为 `idle` 但包含有效预览的节点也会迁移为可选素材。
- 图片与视频节点统一显示最多 3 个素材缩略图，超出数量通过“更多”面板查看。
- 视频首帧、尾帧与参考素材显示真实预览；缩略图上的删除按钮会同时解除对应连线。
- 隐藏面向内部执行器的“上游语义”文本，后端仍可在执行时合并上游数据。
- 底部工具栏显示当前缩放百分比。
- 文本、图片、视频、音频生成输入区统一宽度；提示词随内容自动增高，并设置最大高度防止节点无限膨胀。
- 生成节点继续支持本地 Go 后端队列并行执行。
