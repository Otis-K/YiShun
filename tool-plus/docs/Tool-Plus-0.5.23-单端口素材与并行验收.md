# Tool Plus 0.5.23 单端口素材与并行验收

验收日期：2026-07-19

## 本次闭环

- 每个节点界面仅保留一个左侧智能输入点和一个右侧智能输出点；连接时由 SDK 根据上下游媒体类型映射内部语义端口。
- 连线成功即作为当前节点素材；未连线的画布资产不再自动出现在“选择素材”列表。
- 首帧、尾帧和参考素材支持画布中央预览；素材列表使用横向缩略图，悬浮显示对应提示词。
- 输入框按内容自动增高且不显示内部滚动条。
- 本地模型任务队列并行上限调整为 5，第 6 个任务进入等待队列。
- 生成前按模型能力校验素材数量：图片模型最多 14 张；Seedance 2.0 Pro 最多 4 张参考图、3 个参考视频和 1 段音频，首尾帧模式不能与普通参考素材混用。
