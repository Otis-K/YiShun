# Tool Plus 0.5.24 素材库与首尾帧验收

验收日期：2026-07-19

## 修复内容

- 视频节点的首帧、尾帧不再把图片缩略图或参考图片渲染为节点主预览；选中后仅显示已选状态，点击时在画布中央弹层预览。
- 首尾帧只能通过“选择素材”明确指定；节点连线只进入普通参考素材栏，不再自动占用首帧或尾帧。
- 清除首帧或尾帧时，如果该素材来自当前节点连线，会同步移除对应 edge；未连线的手动素材只清除槽位。
- “选择画布素材”展示当前画布全部可用图片、视频和音频；当前节点素材栏只展示已连线或已手动选择的素材。
- 素材选择器宽度调整为 460px，素材卡横向排列并支持滚动；悬浮素材显示其提示词。
- 生成节点固定宽度调整为 720px；文本输入区域保持宽度稳定，并根据内容自动增加高度，不显示文本滚动条。
- 模型任务并行上限保持 5，超出任务进入队列。
