# Tool Plus 0.5.25 素材库缩略图与预览验收

验收日期：2026-07-19

## 问题原因与修复

- 旧实现优先使用 `previewKind` 推断整个节点的媒体类型，视频节点遗留的首帧图片因此被错误识别为图片素材，或被当作视频缩略图展示。
- 现在生成节点优先以节点生成类型确定媒体种类，并要求缩略图种类与节点种类一致。视频节点的 `previewKind=image` 会被视为遗留首帧而跳过；只有真实视频结果地址才进入视频素材库。
- 素材库改为固定 4 列，默认显示最多 4 行；第 17 项开始通过素材区域纵向滚动查看。
- 素材卡拆分为“预览”和“使用”两个动作：单击缩略图在画布中央打开图片预览或视频播放器，点击右上角加号才把素材加入当前节点。
